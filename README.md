Number Guessing Game
Project: PS No. 4 – Number Guessing Game
Course: B.Tech Computer Science and Engineering
Language: Python 3

Description
The computer selects a number from 1 to 100. The player gets five valid guesses. The program gives “Too low” or “Too high” hints, validates input, and offers a play-again option.

Run
Install Python 3.
Open this folder in VS Code.
Open the terminal in this folder.
Run: python number_guessing_game.py
Testing mode
TESTING_MODE = True fixes the secret number at 42 for the college test cases. Change it to False for normal random gameplay.

Rules
Valid guesses must be whole numbers from 1 to 100.
Invalid text and out-of-range values do not consume an attempt.
The player gets at most five valid attempts.
